# Web Summit Lisboa 2026

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma página web inspirada no evento **Web Summit Lisboa 2026**, realizada no âmbito de um trabalho académico em contexto escolar.

O principal objetivo é criar uma página informativa e visualmente apelativa, que apresente o evento, destaque as suas características e permita aos visitantes explorar as principais informações relacionadas com a sua participação.


## 🎯 Objetivos

- Desenvolver uma página web moderna e intuitiva.
- Aplicar conhecimentos de desenvolvimento web adquiridos em contexto escolar.
- Criar uma interface visualmente apelativa e responsiva.
- Organizar e apresentar informação de forma clara.
- Simular uma página de divulgação de um evento tecnológico.

## ✨ Funcionalidades

- Apresentação do Web Summit Lisboa.
- Divulgação de informações sobre o evento.
- Destaque das datas e localização.
- Secção dedicada à compra de bilhetes.
- Informação direcionada a empresas interessadas em expor.
- Interface intuitiva e de fácil navegação.
